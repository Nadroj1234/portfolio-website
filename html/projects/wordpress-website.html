WordPress Website Assignment

Requirements

The assignment was to create a blog page for a particular type of job. I was assigned to create a blog site for a professional bowler who wanted to share experiences, tips, and insights with fans and other bowlers.

Pages I Created

  • Main page
  • Mobile version of the main page
  • Blog listing page
  • Mobile blog page
  • Single blog post pages
  • Mobile single blog post pages
  • Posts listing page

What I Learned

The main page took the most time because I had to find a theme that worked well. The blog listing also required work to get the post listings working correctly. The individual blog pages were easier and took less time to create.
