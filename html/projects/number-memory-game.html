Number Memory Game

I created a number memory game where the player tries to remember numbers that are displayed.

The project included a high-score system that stored the player's name and score in a JSON file. I ran into some issues with repeated errors and with adding new names and scores to the high-score list, but I was able to complete the assignment.

What I Learned

This project helped me learn more about working with files, JSON data, scores, and game logic in Python.
