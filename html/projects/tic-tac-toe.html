Tic Tac Toe

I created a Tic Tac Toe game as part of my computer programming course.

One of the biggest challenges was getting the computer's move to work correctly. I had to change the computer move function several times before it worked properly. Once the player and computer moves were working, I was able to complete the rest of the game.

What I Learned

This project taught me the importance of following Python's syntax and rules carefully so that functions and other parts of the program work correctly.
