Dad Joke Machine

I created a dad joke generator that pulled dad jokes from an API. I used Python together with HTML to make the website.

The project included a joke search where users could enter a word and get jokes based on that word. One of the more difficult parts was getting the search to return the correct jokes based on the selected mood or search term.

What I Learned

This project gave me more experience working with APIs, Python, HTML, search functionality, and displaying data dynamically on a website.
