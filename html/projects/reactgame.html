React Game Api Project

I made a react games website using the lgbd database. It was a fairly easy assignment to do. I used jsx, js, css, and html to create this website. You can view 20 games on the home page, search for any game in the database, favorite any game, and view games that are similar to the one you are viewing. This is a link to my github repo: https://github.com/Nadroj1234/react_website_project
